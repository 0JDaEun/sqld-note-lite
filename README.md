# SQLD NOTE v3.3

실제 테이블로 개념을 학습하고, 맞힌 문제를 제외한 문제를 계속 푸는 SQLD 학습 앱. GitHub `master` → Vercel 자동 배포.

**사이트:** https://sqld-note-lite.vercel.app/

## 학습 구조

- **15개 핵심 단원 × 5단계:** 핵심 → 예제 → 함정 → 확인 문제(기존 30문항) → 해당 주제 실전 문제
- **15개 단계별 실제 표·판단표:** 각 단원 3단계, 클릭으로 입력/중간/결과 변경
- **8개 보충 단원:** 함수, 집합, PIVOT, 정규식, 문자열, 날짜, 관리 구문, 그룹 집계
- **문제은행 176문항:** 기존 146문항 + 신규 30문항(정규표현식 7, 날짜 7, PIVOT·UNPIVOT 4, 윈도우 6, 집합 3, JOIN 1, 제약·VIEW 2)
- **85개 실행형 문항:** SQLite에서 입력 데이터 → SQL 실행 → 결과표 재검증. **나머지 91문항은 개념형·Oracle 고유 문법 등으로 실제 Oracle에서 실행 검증하지 않았음.**
- **보기별 해설:** 기존의 수작업 해설과 규칙 기반 설명을 구분하여 표시. 신규 30문항은 보기마다 독립적으로 근거 작성.
- **문제 상태:** 미풀이 / 오답 / 모름 / 정복. 정복한 문제는 자동 출제에서 제외.

## v3.3 개선 사항

1. 기존 정규표현식 2문항의 잘못된 PIVOT 분류를 정정했다. 영구 문제 ID는 유지한다.
2. 정규표현식·날짜 함수·PIVOT·윈도우 등 취약 범위에 자체 제작 문제 30개를 추가했다.
3. 보충 단원에서 해당 유형의 실전 문제로 직접 이동한다.
4. 클라우드 기록 읽기에 실패했을 때 **다시 연결** 버튼을 제공한다. 이미 정복한 서버 기록은 오래된 로컬 오답 기록으로 되돌리지 않는다.
5. DBMS 실행 검증 결과와 Oracle 기준 편집 검토 결과를 명확히 구분하여 표시한다.
6. v3.2의 15개 시각 모델, 15개 × 3단계 실행 표, Google 로그인, 기존 학습 기록은 보존한다.

## 데이터 연동

새 DB를 만들지 않고 DEVLOG Supabase 기존 `sqld_note_snapshots`, `sqld_question_states`, `sqld_record_answer`를 사용한다. 본 버전에서는 기존 DB 스키마, 정복 상태, 문항 고유 ID, 로컬 저장 키를 변경하지 않았다. 사용자별 RLS는 그대로 유지한다.

Google 로그인 후 **실제 계정의 다른 기기 간 동기화**는 아직 종단 간 검증하지 못했다. 계정 로그인을 정상적으로 마쳤는지와 클라우드에 저장되었는지를 사용자 기기에서 확인해야 한다. 모의 브라우저 클라우드 읽기 실패→재시도/정복 우선 동작은 통과했다.

## 문제 출처·검수 한계

공개된 복원 기출 원문을 복제하지 않고 직접 작성한 학습 문제다. Oracle 고유 함수(`REGEXP_*`, `PIVOT`, 날짜 함수 등)의 설명과 예상 결과는 Oracle 공식 문서를 참고해 편집 검토했으나 실제 Oracle DB로 일괄 실행 검증하지 못했다. 기존 129개 규칙 기반 보기별 설명은 추가 수작업 개별 검수가 필요한 초안이다.
