# SQLD NOTE v3.5 — 한 페이지 전체 범위 요약 · P0 누락 개념 보강

운영 사이트: https://sqld-note-lite.vercel.app/

## 학습 구조

- **전체 개념 한 페이지**: `#quick-reference` — 2024년 개편의 세부 출제 범위를 30개 학습 항목으로 정리. 1과목 10, SQL 기본 8, SQL 활용 8, 관리 4. 핵심 원리·판별 질문·함정·미니 데이터 표 30개, 검색, 과목 이동, 예제 펼치기, 인쇄 및 관련 문제 바로가기.
- **핵심 개념**: 기존 15개 단원, 5단계(핵심→예제→함정→확인→실전), 확인 문제 30개 유지.
- **보충 개념**: 기존 8개에 5개 추가하여 13개. 신규: 업무 트랜잭션 모델링 / NULL 속성 모델링 / 본질·인조식별자 / 속성 분류·도메인 / 표준 JOIN. 신규 5개 SQL 예제의 입력·출력은 SQLite로 실행 대조.
- **실전 문제은행**: 226 → **247문항**(독자 제작 21문항 추가). 기존 226개 문항의 ID·본문은 변화 없이 보존. 기존 `wrong`/`unknown`/`mastered` 상태 로직도 변경하지 않음.
- **난이도**: 하·중·상은 편집 추정치, 실측 난이도가 아님. **빈출도**는 독립 복원 회차별 근거 미확보로 `미집계` 표시. 기존 15개 단원의 무근거 `S등급` 표시는 `핵심 범위`로 교체.

## QA

`python scripts/validate_content.py`를 실행하면 30/30 범위, 30/30 미니표, 13 보충, 247문항, 신규 문항 ID, 기준선 226문항 동일성, 집계·연결·빈출도 표시를 검사합니다. 브라우저 테스트에서는 360·390·430·768·1440px에서 가로 넘침 0, 검색·예제 펼치기·보충 단원·관련 문제·정답 제출·홈 이동 및 JavaScript 예외 0을 확인했습니다.

## 공식 범위 근거 및 한계

2024년 제52회부터 적용된 SQLD 개편 대비표(2023.10 교육기관 공지): https://m.hrd.wowpass.com/Wanaeca/HelpDesk/Notice/View?Bid=3431164

공식 발행기관: https://www.dataq.or.kr/

30개 항목은 공개 개편표를 바탕으로 학습용으로 재구성한 목록이며 공인기관이 게시한 최신 원문을 그대로 복제한 문서가 아닙니다. `빈출` 레이블에는 조사로 확인한 독립 출제 회차 통계가 없으므로 숫자 등급을 부여하지 않았습니다. 기존 SQLite 검증 125문항을 Oracle 자체 실행 검증이라고 주장하지 않습니다. 새로 제작한 객관식 21문항은 **편집·논리 검토**이며 Oracle 실행 인증이 아닙니다. 외부 SQLD양파·복원 CBT 원문은 포함하지 않습니다.
